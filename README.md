# DEMO HUNTER

A fast-paced pixel-style browser game inspired by the dark atmosphere of the
Upside Down.

Players take the role of a Hunter and must survive waves of incoming
Demogorgons while automatically firing two weapons. The objective is simple:

> Survive longer. Destroy more Demogorgons. Reach a higher rank.

The game includes a global online leaderboard powered by Supabase, allowing
every Hunter's score to be recorded and ranked against other players.

---

## 🎮 Game Overview

**DEMO HUNTER** is a browser-based arcade survival shooter built using:

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- HTML5 Video
- HTML5 Audio
- Supabase

The game does not require a game engine or external controller.

Everything runs directly inside the web browser.

---

## 🕹️ Gameplay

The player controls a Hunter positioned at the bottom of the screen.

Demogorgons continuously enter the battlefield from above.

The Hunter's weapons fire automatically while the player controls horizontal
movement.

### Objective

Survive for as long as possible and destroy as many Demogorgons as possible.

The game ends when all three lives are lost.

Your final result contains:

- Demogorgons destroyed
- Survival time
- Wave reached

Your score is then submitted to the online leaderboard.

---

## 🎯 Controls

| Key | Action |
|-----|--------|
| `A` | Move Left |
| `←` | Move Left |
| `D` | Move Right |
| `→` | Move Right |

### Weapon

The weapons fire automatically.

The Hunter uses a two-gun firing system:

- Right weapon fires vertically
- Left weapon fires diagonally toward the left

The dual-gun system is intentionally retained to allow enemies appearing on
the far-left side of the battlefield to be hit.
